How I run engineering now

One change, four stages

I have worked this way since early 2026. Speed comes from the agents. Safety comes from the order of the work: the plan comes first, and nothing ships until someone other than its author has checked it.

01 Plan

Architecture and plan

I set the architecture. A team-lead agent plans the work with me and splits it into tasks.

03 Check

Review and test

Separate reviewer and tester agents check every change against integration, end-to-end and infrastructure tests. Rejected work goes back to the coding agents.

100% integration test coverage

Approved changes go to production, including custom features for individual clients.
